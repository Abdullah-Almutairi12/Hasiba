# Auto-captured screenshots

Files in this directory are generated by `pnpm --filter @workspace/scripts run capture-docs-screenshots`.

Layout:

```
screenshots/
  ar/<slug>.png
  en/<slug>.png
```

The capture script runs:
- as a manual command for local previews, and
- automatically from `scripts/post-merge.sh` after every successful task merge
  so deployed docs always match the deployed app.

Do not edit these files by hand — they will be overwritten on the next capture run.
