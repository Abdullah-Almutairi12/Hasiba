# Auto-captured screenshots

Files in this directory are generated by `pnpm run docs:capture` from
the repo root (alias for `pnpm --filter @workspace/scripts run
docs:capture`). That single command — implemented by
`scripts/docs-capture.sh` — wires up everything that used to be
manual:

1. Exports `LD_LIBRARY_PATH` with the NixOS paths for `libgbm` (mesa)
   and `libsystemd` (systemd-minimal) so Playwright's bundled chromium
   can `dlopen` them.
2. Installs the chromium browser bundle under
   `~/.cache/ms-playwright` if it is missing.
3. Spawns the `api-server` (port 8080) and `erp-system` (port 19692)
   services in the background and waits for both to respond through
   the shared proxy at `http://localhost:80`.
4. Upserts a dedicated manager-role user (`docs-capture@hasba.ai` by
   default) via `pnpm --filter @workspace/scripts run ensure-capture-user`
   so the capture session can log in without depending on `seed`.
5. Sets `DOCS_CAPTURE_ENABLED=1` and runs
   `capture-docs-screenshots.ts` against that local stack.
6. Stops the background services on exit.

Layout:

```
screenshots/
  ar/<slug>.png
  en/<slug>.png
```

## Required env (no defaults for credentials)

Because the bot account is created with `role=manager`, the wrapper
refuses to run without explicit opt-in:

| Variable | Required | Notes |
|---|---|---|
| `DOCS_CAPTURE_DEMO_TENANT_ACK` | ✅ must be `1` | Confirms you are pointed at a dedicated demo tenant, never production. |
| `DOCS_CAPTURE_EMAIL` | ✅ | Login email for the bot user. |
| `DOCS_CAPTURE_PASSWORD` | ✅ | Must be ≥ 16 chars. Generate randomly per environment; do not commit. |
| `DOCS_CAPTURE_BASE_URL` | optional | Defaults to `http://localhost:80`. |

If any of these are missing or weak, the wrapper exits early and
nothing is provisioned or overwritten. `scripts/post-merge.sh` also
invokes `pnpm run docs:capture`, but it is gated on the same env —
post-merge runs become a no-op unless the operator has explicitly
configured a demo tenant.

Do not edit these files by hand — they will be overwritten on the
next capture run.
