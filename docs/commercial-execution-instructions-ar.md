# حاسبة.AI — مرجع تنفيذ الدفعات التجارية المعتمد

**المصدر:** الأمر التنفيذي التفصيلي الذي أرسله صاحب المشروع في جواب تحديد مرجع التنفيذ، بإصدار 23 أكتوبر 2026. هذا تثبيت لقراراته ومعايير قبوله لاستمرار العمل بين الجلسات؛ ليس تقرير إنجاز أو سجل متطلبات بديلًا. يبقى `enterprise-requirements-ar.md` سجل المعرفات الأصلية الـ73، و`commercial-execution-status-ar.md` سجل النسخ والاختبارات والنتائج ونقطة الاستئناف.

## قواعد العمل المشتركة

- منصة حاسبة القائمة والمستودع `Abdullah-Almutairi12/Hasiba` والفرع `sync/hasiba-erp-20261023`؛ لا مشروع أو Fork أو مستودع بديل، ولا استبدال main أو أرشفة الموقع التعريفي. أي انتقال لاحق إلى main تغيير منفصل واضح الأثر.
- افحص الموجود وأعد استخدامه. هوية الطباعة واللقطات التاريخية والشعار ومحرك Chromium والخط العربي وإسناد البائع ودفتر العمولة والبيع/المرتجع القائمة ليست مطلوبات لإعادة البناء.
- دفعة واحدة في كل مرة، ثم التي اجتازت تبعياتها تلقائيًا، دون إذن بدء لكل دفعة أو توليد مهمتين جديدتين بعد كل إنجاز. لا توقف مصطنع عند نهاية يوم؛ التوقف عند إنجاز المتاح أو مانع حقيقي، وعند حد تشغيل احفظ حالة الاستئناف ولا تدع استمرار العمل بعد توقف الجلسة.
- السعودية أولًا. الدول اللاحقة ملفات إعداد وسياسات مؤرخة واختبارات منفصلة، لا ادعاء امتثال عالمي.
- إدارة/محاسبة/HR/CRM على الويب وPWA. نموذج Windows للكاشير بـElectron وReact المشتركة وخدمات الخادم نفسها، وقبول أجهزة مستقل. واجهات الجوال والآيباد ملائمة للدور، ومسار التطبيقات الأصلية يحدد بعد اختبار الأجهزة؛ PWA ليست تطبيق متجر أصليًا.
- الموقع العام، الحساب والإعداد، ومساحة العمل الخاصة واجهات منفصلة. ملكية منشأة أو إدارة المنصة لا تمنح دخول بيانات منشآت أخرى ضمنيًا.
- تفصل الحالة إلى: ثبت، يحتاج تحسينًا، لم يختبر، متعذر بمانع. لا واجهات وهمية أو محاكاة موصوفة كتكامل حي أو PDF/QR موصوف كقبول زاتكا.
- المالية والمخزون والرواتب على قواعد منفصلة مصطنعة، بأموال دقيقة وذرية ومنع تكرار وحماية الشركة والفرع في الخدمة والتصدير والمرفق.
- تطوير محلي واختبارات معزولة وترحيلات تجريبية وPush نظيف للفرع المحدد مصرح بها بعد فحص التشغيل الآلي. الإنتاج وترحيله والدفع والصرف والتحويل والبريد/رسائل العملاء والإرسال الضريبي ورفع تخزين خارجي ليست مصرحًا بها. لا أسعار نهائية أو اشتراك مدفوع دون قرار لاحق.
- العربية RTL وTajawal والنص المختلط، وحالات تحميل وفراغ وخطأ وصلاحية وحفظ المدخلات عند الفشل. كل زر وظيفة حقيقية أو سبب واضح لعدم التوفر.
- بعد ثلاث محاولات فاشلة للسبب نفسه شخّص المانع، وأكمل فقط العمل المستقل عنه. لا تخفض معيار قبول أو تضعف اختبارًا لزيادة أرقام النجاح.

## بوابة التسليم المشتركة

كل تقرير دفعة يذكر: الهدف ومعرفات الأصل؛ ما تغير وما أعيد استخدامه والملفات والترحيلات؛ معايير القبول المثبتة؛ الأعداد الدقيقة للنجاح والفشل والتجاوز وأسبابه؛ حدود المتصفح والأجهزة؛ الأخطاء والمعالجة والموانع؛ النسخة والبصمة ونقطة الرجوع؛ حالة المحلي والبعيد وأول خطوة لاحقة.

تحقق مرتبط بالمصدر: اختبارات مناسبة أثناء التطوير، ثم `pnpm run verify` على مصدر التسليم دون خلط نجاح نسخ مختلفة. لا إعادة فحص بلا تغيير ذي أثر، ولا ادعاء نجاح جولة توقفت أو أخفقت. Push لا يعني نشرًا؛ الرابط المؤكد للـCommit بعد قراءة المرجع البعيد. المخرجات المستثناة من Git ليست موجودة في المستودع ولا يغني رفع الشيفرة عن نسخ البيانات.

## الدفعة 0 — تثبيت التسليم

راجع HEAD والبعيد والتعديلات وسجل الربط والنسخ المحلية الأربع القديمة، واحفظ نقطة رجوع دون فقد التاريخ. تحديث النتائج القديمة بإضافة أحدث دليل لا بمحوها. فصل التجربة التجارية في بيئة مصطنعة، وإزالة بيانات الحسابات التجريبية والاعتمادات والأداء غير المثبت من الصفحة العامة، ومعالجة الحساب في نطاق آمن معلوم.

**القبول:** نسخة معلومة وفروق مفهومة ولا فقد شيفرة، ونتيجة verify مربوطة بمصدرها، وتفريق Commit/Push/نشر. نقص GitHub لا يمنع تطويرًا محليًا محفوظًا.

## الدفعة 1 — الأساس المؤسسي

مجموعة وشركة قانونية وفرع وإدارة ومستودع وPOS؛ الفرع ليس شركة مستقلة. إعداد الشركة يورث للفرع مع تخصيص معلوم واختلاف نشاط الفرع.

قدرات عرض/إنشاء/تعديل/حذف مسودة/تصدير/مراجعة/اعتماد/ترحيل/عكس بنطاق شركة وفرع وإدارة ومبلغ وحساسية. قوالب مدير ومحاسب فرع ومحاسب رواتب ومشتريات وكاشير وبائع ومدقق وموظف، قابلة للتخصيص دون صلاحيات واسعة ضمنية.

موافقات بتسلسل وتفويض مؤقت وبديل وتصعيد وتوازٍ فقط حيث يتطلبه نوع الطلب. منع الاعتماد الذاتي حسب السياسة. تعديل جوهري للمبلغ أو البيانات بعد الموافقة يبطلها أو يفرض إعادة مراجعة موثقة.

**القبول:** شركتان وفروع متعددة ومحاولات API لتجاوز الأدوار، ونطاق رواتب محمي، ومنع مشغل المنصة من دخول بيانات العميل افتراضيًا. يبقى تعميم كل وحدة مفتوحًا حتى فحصها.

## الدفعة 2أ — خمسة قوالب وتعديل سريع

«تصميم المستندات» ضمن الإعدادات بإذن إدارة القوالب، مستخدمًا هوية المنشأة والشعار القائمين دون سجل منشأة موازٍ.

خمسة A4 مختلفة في الترتيب والكثافة: رسمي تقليدي؛ حديث بهوية العلامة؛ اقتصادي مدمج للصفوف الكثيرة؛ عربي/إنجليزي متوازن؛ خدمات وتوريد بمراجع وشروط واعتماد واضح. لا يكفي اختلاف اللون. تخطيطان مستقلان 58/80 مم، لا يعدان من الخمسة ولا يصغّران A4 اعتباطيًا.

تعديل الشعار ورفعه وإزالته حيث يسمح نوع المستند، وتحجيم بنسبة صحيحة ومحاذاة، والألوان والخط وحجمه المقروء والهوامش ومواقع البائع والعميل وأعمدة البنود الاختيارية والشروط والملاحظات والبنك والتذييل. نسخ القالب وتسميته وحفظه وافتراضي بحسب الشركة والفرع ونوع المستند.

**القبول:** اختيار القوالب الخمسة وتعديلها وحفظها وفتحها مجددًا وPDF فعلي؛ معاينة مصطنعة بلا فاتورة أو رقم مالي؛ عربية طويلة ونص مختلط وصفحات متعددة وشركة مسجلة وأخرى غير مسجلة وغياب الشعار وبائع تاريخي.

## الدفعة 2ب — محرر التصميم المتقدم

محرر كتل للرأس والشعار والمصدر والعميل والمراجع والبنود والمجاميع والضريبة وQR والشروط والتوقيعات والتذييل. سحب وإفلات وأزرار ترتيب للوحة المفاتيح، ومحاذاة وعروض وفراغات وأعمدة وخطوط وتراجع/إعادة واستعادة الأصل وبداية بسيطة بالكتل الإلزامية.

المخطط محدود وآمن، لا JS أو SQL أو HTML خام ولا صور خارجية عشوائية. أصول الشركة مملوكة ومتحقق من نوعها وحجمها، والمعاينة وPDF من محرك العرض نفسه دون تحميل موارد غير معتمدة.

حقائق الخادم لا يعدلها التصميم: الضريبة والمجاميع والرقم والتاريخ وهوية الإصدار. منع إخفاء/قص/شفافية/إضعاف قراءة الإلزامي، بحسب نوع المستند وحالة التسجيل والبلد المدعوم ومصدر موثق؛ لا رقم ضريبي إلزامي لغير المسجل.

دورة مسودة/معاينة/تحقق/نشر نسخة/افتراضي/استعادة سابقة. لقطة القالب والأصول مع الإصدار تحفظ الشكل والبيانات عند إعادة الطباعة. لا تعديل XML أو توقيع أو QR تاريخي؛ القديم بلا لقطة يستخدم مسارًا قديمًا موثقًا بلا ادعاء شكل تاريخي غير محفوظ.

يبدأ بفواتير العملاء والدائن والإيصالات ثم العروض وأوامر الشراء وسندات القبض والصرف والإقفال حيث يسمح مخطط كل نوع. لا تغيير لأصل مستند المورد المرفوع.

**القبول:** تعديل كبير وآخر بسيط وحفظ اختلافهما، وتطابق المعاينة وPDF؛ منع تجاوز الإلزام عبر API واختلاط شركتين؛ إصدار ثم تغيير القالب والشعار وإعادة طباعة القديم دون تغيير شكله المحفوظ أو أثره؛ QR مستخرج ونص عربي قابل للبحث ورؤوس جداول متكررة وفواصل صفحات. اختبار تنزيل المتصفح مع تصريح واضح إن لم يرصد تنزيل النظام.

## الدفعة 3 — العامة والحساب والإعداد ومساحة الدور

الموقع القائم يشرح الأنشطة والميزات المثبتة وحالة التكاملات، بروابط حقيقية للدخول والتجربة والتواصل والمساعدة والخصوصية والشروط، وخطط بلا أسعار ملزمة أو أرقام أو اعتمادات مختلقة.

الدخول والخروج والاستعادة الآمنة ودعوات الموظفين والجلسات والتحقق الإضافي للحسابات الحساسة حيث يدعمه النظام؛ عدم كشف وجود الحساب وحدود المحاولات ومنع تجاوز التحقق وحماية الإعدادات.

عضوية واحدة إلى المساحة؛ متعددة إلى اختيار شركة/فرع مسموح. إعداد يستأنف: منشأة ونشاط وتسجيل ضريبي صريح وفرع ومستودع وفريق وأدوار وهوية وقالب وأرصدة/استيراد بمعاينة ومصالحة. تجاوز المبيعات تنبيه لا تسجيل ضريبي تلقائي.

مساحة قابلة للترتيب للمهام والموافقات والتنبيهات والمستندات والاختصارات والمؤشرات بحسب الدور، بروابط تفصيل حقيقية ونطاق وفترة وعملة ومصدر وتاريخ تحديث، دون جمع عملات غير مفسر.

**القبول:** زائر إلى دخول وإعداد مستأنف وأول إجراء؛ مدعو ومتعدد الشركات وفشل/انتهاء جلسة وبحث لا يكشف خارج الصلاحية؛ تجربة تجارية معزولة.

## الدفعة 4 — PWA والأجهزة ونموذج Windows

manifest وأيقونات وتثبيت وتشغيل مستقل وتحديث مضبوط؛ اختبار كمبيوتر/آيباد/جوال حقيقيًا حيث توافر وتسمية المحاكاة. لا تحديث أو Reload أثناء تحصيل مجهول. أصول عامة مضبوطة التخزين؛ لا مالية ورواتب في Cache عام.

المسودات والنيات المحلية مقيدة بالمستخدم والشركة والجهاز، مع خروج وتبديل شركة دون تسرب أو مسح دليل مالي معلق. فصل فتح التطبيق بلا شبكة عن المسودة عن البيع المالي دون اتصال؛ هذه الدفعة للاتصال والمسودات والاستعادة، والبيع لبوابة 12د.

Electron داخل المشروع نفسه، واجهة مشتركة وطبقة أجهزة/تخزين منفصلة ومنطق مالي على الخادم؛ PostgreSQL مرجع وSQLite اقتراح للطابور والحد اللازم لا نسخة قاعدة كاملة، ولا أسرار/اتصال إنتاج مباشر لدى العميل.

طابعة Windows محددة، اختيارها و58/80 والطباعة المباشرة والفشل وإعادة الطباعة؛ فشل الورق لا يلغي بيعًا مؤكدًا أو يعيده. إرسال مهمة ليس إثبات خروج ورق. الدرج والقارئ والشاشة يحتاجان الأجهزة/SDK.

عزل سياق وsandbox وNode معطل في العرض وIPC محدود ووجهات شبكة مقيدة وشيفرة موثوقة وتحديثات موقعة وتراجع وتوقيت بعيد عن التحصيل.

مزامنة API بهويات ثابتة وإقرار وتأجيل وسجل ومصالحة وحالات محلي/بانتظار/مؤكد/تدخل. لا آخر تعديل يفوز في الفواتير والقيود؛ سياسات تعارض معلنة وتأخر ظاهر بين الفروع. لا مزامنة والجهاز مطفأ؛ بيان هل تعمل داخل التطبيق أو خدمة خلفية مصرح بها ومراقبة.

**القبول:** تثبيت/تشغيل/تحديث/خروج/تبديل/انقطاع مع سلة ودفع معلق دون تكرار. مثبت Windows فعلي وقياسات بدء وذاكرة وسلة وطباعة وخطوط واستعادة طابور؛ إن لم تتوفر Windows فحزمة/خط بناء وخطوات واضحة بعنوان «غير مختبر على Windows»، لا قبول مزعوم.

## الدفعة 5 — المخزون والوصفات والتكلفة

وحدات وتحويل ومتغيرات وباركود ودفعات/تسلسل/صلاحية ومحجوز/متاح/في الطريق وتحويل باستلام مستقل وجرد وتسويات بأسباب وصلاحيات. وصفات ومكونات وإضافات وهدر وتجميع وإنتاج خفيف على المحرك القائم، مع وقت استهلاك يمنع الخصم عند الطلب والتحصيل مرتين.

**القبول:** تحويل جزئي واستلام وجرد وتسوية ومنع إعادة الحركة وبيع متزامن محدود المخزون ومرتجع بتكلفة الأصل وتغيير وصفة دون إعادة كتابة بيع سابق. لا إعادة تقييم مبيعات بتاريخ اليوم.

## الدفعة 6 — تجزئة

جدول باركود سريع وبحث ولوحة مفاتيح وكمية/وحدة/سعر/خصم/ضريبة/إجمالي، ومتغيرات وعملاء وأسعار وصلاحيات وعروض وولاء وسلال معلقة ووردية. الدفع داخل السلة والبائع مستقل وحماية الإعادة. الدفع المقسم مجموع مطابق وحالة مثبتة لكل جزء؛ لا إعادة جزء مؤكد أو إكمال مجهول.

**القبول:** باركود ومتغير ووحدة وخصم مصرح وسلة معلقة ومرتجع جزئي ببائع الأصل ونسخة تاريخية؛ فقد رد لا يضاعف الفاتورة أو المخزون أو القيد.

## الدفعة 7 — مطاعم ومقاهٍ

بطاقات لمس وأقسام متفرعة وصور وأحجام وإضافات ومجموعات إلزامية وحدود وأسعار وتحضير؛ محلي/سفري/توصيل وطاولات وفتح/تعديل/نقل/دمج/تقسيم بصلاحية وسجل. تذكرة مطبخ لا تكرر عند الإعادة، وتعديلات وإلغاء واضحان. التقسيم يحفظ الكميات والضريبة والخصومات والمبالغ ويمنع تحصيلين متضاربين.

**القبول:** رحلة طاولة وحجم وإضافة وتعديل بعد التحضير ونقل وتقسيم وتحصيل ومرتجع وتزامن وتكلفة دون ازدواج. الطعام المحضر لا يعيد خاماته تلقائيًا؛ للمعلب سياسة مستقلة. شاشة مطبخ/عميل مصرح بها لا تعني اختبار معدة فعلية.

## الدفعة 8 — المحاسبة

حسابات وأستاذ وميزان وقوائم إلى مصادر، تخصيص قبض/صرف ومقدمات وأعمار وائتمان وخزائن وبنوك وتسوية وتوقع سيولة مفسر؛ أصول ورسملة وإهلاك واستبعاد وقيود دورية واستحقاقات؛ أبعاد ومراكز وتوزيع وموازنات والتزامات وانحرافات؛ مشاريع وعملات وفروق وفترات وسنة؛ معاملات شركات ومصالحة واستبعاد وتجميع بنطاق معلن لا توحيد شامل مزعوم.

**القبول:** دورة صغيرة متوازنة بلا كتابة في فترة مغلقة أو ترحيل مكرر؛ تسوية قابلة للمراجعة وأصل كامل وموازنة ومشروع متعدد الأبعاد ومعاملة شركتين وأثر تقارير. لا تعديل مرحل، بل عكس/تسوية؛ إعادة فتح بسبب وصلاحية. الحسابات حتمية لا نموذج لغوي.

## الدفعة 9 — مشتريات وتوريد وعقود

احتياج موظف/فرع وموازنة والتزام وموافقة وعروض ومقارنة وأمر واستلام جزئي ومطابقة أمر/استلام/فاتورة وخدمات وفواتير جزئية ومرتجع وتكاليف إضافية ودفع ومصالحة وتقييم مورد وعقد وتجديد.

توريد المنشأة للعميل/الجهة دورة مستقلة: فرصة/منافسة ومرجع يدوي ومرفقات ومتطلبات وعرض وضمان وانتهاء وعقد وتسليم ومستخلص ومطالبة وتحصيل وربحية. لا تكامل اعتماد.

**القبول:** احتياج إلى استلام جزئي وفاتورة ومطابقة واعتماد وسداد موثق تجريبي؛ رحلة توريد مستقلة بأثر مالي وصلاحيات.

## الدفعة 10 — HR والموظف والرواتب

هيكل ووظائف وتوظيف ومرشح وتعيين وعقد وتهيئة ووثائق؛ بوابة ذاتية لملف وقسيمة وإجازة ورصيد وحضور وطلبات ومصروف وعهد وسلف وأهداف وإنجاز وتقييم وتدريب وإنهاء وإخلاء. مدير الأداء لا يرى الرواتب كلها.

ورديات وإضافي وإجازات واستقبال حدث جهاز منفصل عن اختبار الجهاز. رواتب إعداد/مراجعة/اعتماد/تجهيز صرف/دليل تنفيذ ومصالحة/ترحيل؛ لا اعتماد يساوي دفعًا.

عمولات وأهداف على الدفتر القائم، دون صرف مزدوج؛ المرتجع اللاحق تسوية واحدة لا تعديل تاريخ راتب/عمولة مصروفة أو معتمدة. سياسات بلد/عقد مؤرخة، لا استقطاع أو جزاء عام دون مرجع معتمد. الجزاء واقعة/أدلة/رد/مراجعة/قرار/اعتراض/تنفيذ مصرح، لا خصم AI تلقائي.

**القبول:** طلب إجازة ومصروف وإنجاز ومراجعة مدير ومسير مصطنع ومراجع آخر وتسوية مرتجع وحالة جزاء واعتراض بسجل؛ لا صرف بنكي.

## الدفعة 11 — CRM

عميل موحد داخل الشركة يربط الاتصال والفرص والعروض والطلبات والفواتير والتحصيل والمرتجعات والولاء والتذاكر والتفاعل. دمج بتصور واعتماد يحفظ الوثائق والمراجع، لا دمج بين الشركات تلقائيًا.

مصادر وتوزيع ومراحل ومهام ومواعيد وفوز/خسارة وتوقع وأهداف وربط بائع/فاتورة؛ شرائح وحملات وموازنة وتقويم وقسائم وعروض وموافقة قنوات وإلغاء اشتراك، وقياس صافي مبيعات/مرتجع/تكلفة/ربح بإسناد معلن. خدمة عملاء المنشأة ليست تذكرة دعم المنصة. رسائل مسودة حتى الصلاحية والتكامل والموافقة.

**القبول:** محتمل إلى فرصة وعرض وفاتورة ومرتجع، وعائد صافي حملة ودمج بلا فقد وتذكرة بسجل وإلغاء يمنع إرسالًا لاحقًا؛ لا إرسال خارجي.

## الدفعة 12أ–د — التكاملات

حالات منفصلة: غير مهيأ/مجهز برمجيًا/محاكاة/بيئة مزود تجريبية/مفعّل ومتحقق فعليًا. مفاتيح وحسابات كل شركة معزولة ورموزها لا تسجل.

- **12أ:** مواصفات زاتكا الرسمية الحالية؛ XML وتحقق وتوقيع وشهادات وتجديد وإبلاغ/اعتماد وأرشيف وإشعارات ورفض وتحذير وإعادة دون تكرار حسب نوع الفاتورة. أدوات الهيئة وبيئتها حيث الصلاحية. لا تعديل موقع أو QR تاريخي. الإنتاج دليل منفصل.
- **12ب:** سلة وزد وShopify، فحص القائم أولًا؛ مصفوفة حقول واتجاه ومصدر حقيقة للمنتج والسعر والمخزون والطلب والدفع والإلغاء والمرتجع. توقيع Webhook وتكرار وتأخر وخروج ترتيب وحدود وتجديد رمز ومصالحة وإعادة تشغيل؛ استيراد طلب لا يعني تحصيلًا/فاتورة ثانية.
- **12ج:** دفع مطلوب/مؤكد/مرفوض/مجهول/مسترد بدليل وتوقيع ومصالحة؛ تعريف طابعات ودرج وشاشة وحضور وربط وملكية فرع ومصفوفة توافق فعلية. لا USB/Bluetooth/آيباد مزعوم من محاكي. التفعيل الفعلي بوسائله ونطاقه المعتمد فقط.
- **12د:** طابور دائم وهوية ثابتة واستعادة بعد إغلاق وسياسات تعارض مخزون/سعر/صلاحية/أجهزة وترقيم/وقت ومنع تكرار. قيود زاتكا الزمنية ونوع المستند والمزود تراجع فعليًا؛ عند عدم التحقق مسودة واضحة أو منع. لا بطاقة بلا اتصال إلا بدعم مزود صريح، ولا مسح دليل عند تحديث/خروج.

**القبول:** تكرار وتأخر بلا أثر مزدوج، ومصالحة تكشف فرقًا ورفض ضريبي مفهوم وطابعة محددة بدليل حيث توفرت، وعطل بعد حفظ/قبل رد ثم استعادة واحدة. نقص مفاتيح/جهاز يوثق مع استمرار المستقل، ولا يغلق كامل الدفعة.

## الدفعة 13 — AI

جرد الخوارزميات والنماذج والإصدارات ومصادر البيانات. الخمس: توقع مبيعات، فقد عميل، شذوذ، توصيات، مساعد. استخراج الموردين إضافي والتسعير القائم يقيم منفصلًا؛ لا استبدال الخمس بخمسة LLM.

لكل وظيفة خط أساس وتقييم منفصل ومقياس جودة وكلفة وزمن وحد نقص بيانات: اختبار توقع زمني وفروع ومواسم؛ تعريف فقد وجودة ترتيب؛ تنبيه شذوذ بدقة ومراجعة بشرية؛ توصيات بمخزون وهامش؛ مساعد بأرقام صحيحة ومصدر وصلاحية؛ استخراج لكل حقل/بند/ضريبة/مجموع وتكرار ومراجعة قبل الحفظ.

وثائق مقدمي النماذج وقت التنفيذ ومقارنة لا حداثة الاسم، وبيانات مصطنعة/مصرح بها وميزانية محدودة بالإعدادات ونسخة وكلفة ونتيجة وتراجع. لا تكلفة خارجية مفتوحة.

تحسين من ملاحظات معتمدة وجودة وانحراف وتدريب/معايرة عند كفاية بيانات، واختبار لم يتدرب عليه ومقارنة ونشر تدريجي وتراجع. لا تعلم مشترك لبيانات منشأة دون أساس وصلاحية صريحة، ولا كل تصحيح حقيقة. تحديث معرفة المساعد ليس تدريب أوزان.

المساعد يقرأ حسب الصلاحية بمصادر ويجهز مسودات مراجعة، ولا يرحّل أو يغير راتبًا أو يوقع جزاءً أو يرسل حملة أو يصرف تلقائيًا. نقص البيانات معلن، لا نسبة كفاءة عامة.

**القبول:** مقارنة فعلية لكل وظيفة وحدودها ومؤشراتها، وتسرب شركات وحقن تعليمات، وبقاء الحالي إن لم يتفوق المرشح، وتراجع تجريبي ناجح.

## الدفعة 14 — تجربة المنتج والاشتراكات

جرد صفحة/وظيفة لبحث وفلاتر وأعمدة وإجراءات جماعية وتعليقات ومرفقات وسجل ومساعدة؛ لا زر غير مناسب. المؤشرات بمصدر ونطاق وفترة وعملة وتصدير محمي.

استيراد قالب/معاينة/ربط/تحقق/تكرار/اعتماد/مصالحة وتراجع آمن قبل ترحيل. تدريب تجاري معزول قابل للضبط، ومصفوفة بلد/ميزة مدعوم مختبر/جزئي/غير مدعوم، لا عملة تعني دولة مدعومة.

ملحق اشتراكات مؤرخ قابل للتهيئة لوحدات وفروع وPOS ومقاعد دخول وحصة AI بلا أسعار نهائية. سجل HR/بائع بلا دخول ليس مقعدًا تلقائيًا؛ مستخدم على جهازين ليس مقعدين. تجربة وتفعيل وترقية/تخفيض وتجديد/إلغاء وفشل/سماح واستحقاق خادم واستهلاك مصطنع.

**القبول:** حد يطبق بالخادم وترقية/تخفيض دون فاتورة مزدوجة/فقد، ومستخدم بجهازين وموظف بلا دخول وحصة AI واستيراد جزئي خاطئ لا يرحّل. الانتهاء لا يحذف البيانات أو يوقف محاولة مالية معلقة، والأدلة والتصدير المتاحان لا يحجبان بلا سياسة.

## الدفعة 15 — بوابة تجريبية لا نشر تلقائي

رحلات بيع/مرتجع/صرف/إقفال؛ شراء/استلام/مطابقة/دفع؛ تحويل/جرد/وصفة؛ إجازة/حضور/راتب/عمولة؛ فرصة/حملة/تذكرة؛ قالب مخصص وطباعة تاريخية؛ وتكاملات، بشركتين وفروع وأدوار وتزامن وانقطاع.

أمن اعتماديات ودخول وجلسات وصلاحيات وتصدير ورفع وأسرار وموصلات ومراقبة؛ صفر تدقيق مكتبات ليس انعدام ثغرات. استعادة نسخة حقيقية إلى بيئة منفصلة وأهداف تعافٍ بسياسة لا مجرد ملف نسخة.

أحمال معلنة وPOS متعددة وأداء وطوابير وفشل؛ ترقية فارغة ونسخة سابقة ممثلة وتراجع يحفظ الأدلة؛ دليل مسؤول وكاشير ومحاسب وموظف ودعم وتحديث واستعادة ومصفوفة أجهزة فعلية.

**القبول:** نسخة واحدة معلومة وبواباتها المطلوبة ناجحة ومتبعيات/موانع دقيقة وتقرير قابل لإعادة الإنتاج وإصدار تجريبي للمراجعة. لا نشر تجاري أو قبول إنتاجي أو دفع/رواتب تلقائيًا.
