# دليل محرر الفاتورة المتقدم — 2ب

## الوصول والبدء
1. افتح **الإعدادات ← القوالب**؛ المحرر المتقدم موجود تحت إعداد القالب السابق، وليس صفحة منفصلة.
2. حدد المنشأة أو الفرع من محدد نطاق الإعدادات الأصلي. تغيير النطاق يتطلب تأكيدًا.
3. انسخ أحد القوالب الخمسة: رسمي، بسيط، تجاري، حديث، حبر؛ أو انسخ إصدارًا منشورًا إلى مسودة جديدة.
4. أعط المسودة اسمًا واضحًا. لا يتغير أي مستند بمجرد إنشاء المسودة أو حفظها.

## التعديل
- رتب كتل الهوية والعميل والمراجع والبنود والمجاميع وQR والملاحظات والتذييل بالسحب، أو زري الأعلى والأسفل، أو `Alt + ↑/↓`.
- الكتل الإلزامية لا تُحذف. يظهر QR والضريبة وفق حقائق المستند والتسجيل، لا حسب رغبة المصمم.
- غيّر اللون والخط وحجم خط A4 ومحاذاة هوية المنشأة والشعار والنصوص الاختيارية.
- اختر شعار المنشأة أو شعارًا مخصصًا أو إخفاء الشعار؛ رفع PNG/JPEG يمر بخدمة الأصول الأصلية. يحتفظ المستند الصادر بأصل الشعار الذي اختير عند إصداره.
- لوحة A4 مستقلة عن لوحة 80 مم: ترتيب وتباعد وهوامش وأعمدة بيانات وعروض أعمدة وتسلسل البنود. حجم الخط الحراري ثابت للقراءة؛ إعداد A4 لا يصغره.
- الهوامش المدعومة: A4 بين 8 و18 مم، و80 مم بين 3 و5 مم. عروض الأعمدة الخمسة مجموعها100؛ الوصف لا يقل عن25 والإجمالي عن15، وكل عرض بين8 و55.
- استخدم التراجع والإعادة أو `Ctrl/Cmd+Z` و`Ctrl/Cmd+Y`. تكون أدوات التعديل مجمدة أثناء عملية معلقة أو معاينة جارية.
- عند مغادرة تصميم غير محفوظ يظهر تنبيه. يُمنع تبديل المنشأة أثناء عملية مجهولة النتيجة حتى تُحسم.

## الحفظ والمعاينة والنشر
1. احفظ المسودة؛ سترى رقم مراجعتها، ويمكن إغلاقها وإعادة فتحها.
2. أنشئ المعاينات الأربع: A4 قصير، A4 طويل، 80 قصير، 80 طويل.
3. المعاينة ملف PDF فعلي من محرك الطباعة نفسه، وبياناتها مصطنعة؛ لا تصدر فاتورة أو رقمًا ماليًا.
4. تغيير التصميم يبطل المعاينات القديمة لذلك التصميم. لا يسمح الخادم بالنشر دون المعاينات الأربع للتصميم نفسه.
5. انشر صراحةً بعد مراجعة نافذة أثر النشر على المنشأة أو الفرع.
6. المستندات الجديدة تستخدم الإصدار الفعال؛ إعادة طباعة القديم تستخدم لقطته التاريخية ولا تعيد قراءة إعداد اليوم.

## المنشأة والفرع والإصدارات
- يظهر مصدر التصميم الفعال: المنشأة أو تخصيص الفرع أو المسار الكلاسيكي.
- لا يستبدل نشر افتراضي المنشأة تخصيص فرع سابقًا من 2أ دون إجراء صريح.
- يمكن تفعيل إصدار منشور سابق للمستندات **المستقبلية**، أو إعادة الفرع للوراثة. لا تُمحى الإصدارات أو المستندات القديمة.
- أرقام التصميم المعروضة مرتبطة بمراجعة المسودة؛ قد ترى1 ثم2 ثم4 إذا لم تنشر مراجعة3. هذا ليس تكرار نشر؛ رقم تفعيل النطاق وإيصال الطلب منفصلان.
- عند تفعيل المحرر، تبقى إعدادات 2أ محفوظة، لكنها ليست التصميم الفعال لذلك النطاق إلى أن تعود صراحةً للمسار الكلاسيكي.
- صلاحية إدارة التصميم لا تمنح قراءة الفواتير أو طباعتها أو تصديرها أو ترحيل قيود.

## التعارض أو انقطاع الرد
- إذا عدّل شخص آخر المسودة تظهر رسالة تعارض، ويظل عملك المحلي محفوظًا في الشاشة. اختر تحميل نسخة الخادم أو الاحتفاظ بتعديلاتك ثم حفظها فوق المراجعة الحالية بقرار صريح.
- عند انقطاع الرد لا تفترض فشل الحفظ أو النشر. استخدم **تحقق من الحالة**؛ يبقى الطلب المعلق محفوظًا في الشاشة ولا يُعد ملغيًا.
- استخدم **إعادة المحاولة** لحسم الطلب نفسه بالمعرف والجسم نفسيهما. لا تُنشأ نسخة نشر ثانية بسبب إعادة المحاولة.
- عند سحب الإذن يرفض الخادم العملية، وقد تنقلك الواجهة خارج الإعدادات. غياب الزر ليس بديلًا عن حماية الخادم.

## حدود هذا التسليم
- محرر كتل محدود وآمن، وليس محرر JavaScript أو HTML/CSS أو SQL أو صور بروابط خارجية.
- لا يحرر رقم الفاتورة أو هويتها أو تاريخها أو الضرائب أو المبالغ المصدرية، ولا يعيد كتابة XML أو توقيع أو QR تاريخي.
- حافظ مسار58 مم على سلوك2أ؛ لا توجد له لوحة تحرير متقدمة مستقلة في هذه الشريحة.
- الحد التشغيلي الحالي100 مسودة لكل منشأة؛ يعرض سجل الإصدارات أحدث200 إصدار. الإصدارات والأصول المؤرشفة لا تحذف عند تجاوز نافذة العرض.
- تم التحقق من ملفات PDF فعلية؛ نافذة الحفظ في نظام التشغيل وخروج الورق من طابعة حقيقية لم يثبتا بأدوات المتصفح. لا يمثل نجاح PDF قبولًا رسميًا لزاتكا.
- الاختبارات الحالية لا تعني اكتمال ERP أو خلو البرنامج كله من الأخطاء.
