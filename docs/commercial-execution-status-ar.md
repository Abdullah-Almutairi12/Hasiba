## المصدر وحدود هذه الدفعة

اعتمد توجيه المستخدم المرفق في 2026-10-23، مع تقرير التسليم السابق وسجل المتطلبات الأصلي ذي 73 معرفًا. الموجود فعليًا في المرفق الجديد 45 سطرًا من التوجيهات وترتيب الدفعات؛ يشير إلى ملف `Hasiba_Replit_Execution_Plan_AR.txt` وتفاصيل قبول واختبارات أجهزة ومزامنة، لكن ذلك الملف التفصيلي غير موجود ضمن المرفقات الحالية. لا تختلق معاييره ولا تعلن تنفيذها.

العمل داخل المشروع والمستودع والفرع القائمين، دون استبدال main أو أرشفة الموقع التعريفي. لا نشر إنتاجي ولا اختبارات على بيانات عملاء ولا دفع أو صرف أو بريد أو رفع شعارات خارجي. مزامنة الشيفرة إلى GitHub مصرح بها صراحة في التكليف الجديد.

## نقطة البداية والمزامنة

- نسخة تسليم الطباعة والبائع النهائية: `d54c7559c3ad87c8ec6a4d79a33aa1beeb78c14b`، وفحصها السابق 15 بوابة ناجحة، 539 اختبار API ناجح وواحد متجاوز، و69 اختبار واجهة ناجح. هذه نتائج تاريخية وليست فحص هذه الدفعة.
- أضاف الحفظ التلقائي بعدها `bcaf443` لبيانات تعريف المرفقات فقط. بقيت إضافات التسليم الأربع كاملة، ولم تستبدل بنسخة GitHub.
- نقطة الرجوع الجديدة `before-commercial-foundation-20261023` عند بداية العمل. نقطة الرجوع السابقة محفوظة كذلك.
- جلب الفرع البعيد أثبت أنه لا يضيف تغييرات فوق المرجع السابق. رُفعت نسخة البداية كاملة إلى الفرع نفسه، وأكدت قراءة المرجع من GitHub وصوله إلى `bcaf443fdf51b8244b3abc8debeb1fef769d1b02`.
- فُحصت نسخ الملفات المعدلة في الإضافات الخمس غير المرفوعة قبل رفعها، بحثًا عن صيغ المفاتيح الخاصة والرموز المعروفة وملفات البيئة والنسخ الاحتياطية. لم تظهر مطابقة. هذا فحص محدود لمسار الرفع، لا ضمان بأن كامل التاريخ خال من جميع أنواع الأسرار.
- احتُفظ بعنوان المستودع السابق للرجوع، مع إزالة اعتماد مضمّن في عنوانه المحلي. لا تسجل قيمة الاعتماد أو تنسخها. إزالة الاعتماد من الإعداد المحلي لا تعني إبطاله لدى مزوده.

## الدفعة الأولى — التغييرات المنفذة

1. أزيلت بيانات الدخول التجريبية من الصفحة العامة والعبارات غير المثبتة عن الاعتماد الرسمي والانتشار والتوافر ودقة AI والأداء.
2. أرقام المعاينة على الموقع وصفت بأنها توضيحية، وليست مبيعات حية أو دليل أداء.
3. الدخول الاجتماعي والاستعادة الذاتية غير المنفذين يظهران غير متاحين؛ لا تدعي الصفحة إرسال رابط أو تنفيذ خدمة لم تعمل.
4. أزيل ادعاء حماية الدخول بـ2FA؛ وجود علم إعداد وحده ليس إثبات تحدٍ فعلي.
5. الخادم يرفض كلمة المرور التجريبية المنشورة عند الدخول والتسجيل وإنشاء المستخدم وتغيير كلمته. يعتمد المنع على الكلمة، لا على حظر بريد تجريبي ربما غير صاحبه كلمته بالفعل.
6. لم تُغيّر كلمات مرور حسابات قائمة، ولم تُحذف بيانات أو جلسات قائمة. لا يدعى تعطيل حسابات بعينها أو إبطال جلسات قديمة؛ ذلك يحتاج مراجعة مسؤول الحساب وإجراء أمني مستقل مضبوط.
7. أداة البيانات التجريبية القديمة التي تمسح جداول أصبحت ترفض الإنتاج وأسماء القواعد العادية. تتطلب اسم قاعدة منفصلة `hasiba_seed_<16 hex>` وعلم تأكيد صريح، وكلمة قوية مقدمة بأمان عبر `SEED_ADMIN_PASSWORD` قبل أول مسح. لم تُشغّل الأداة.

## الاختبارات والإثبات

- اختبارات حماية أداة التجربة تتحقق من رفض قاعدة تشغيلية والإنتاج وغياب التأكيد وكلمة مرور مفقودة أو ضعيفة، دون فتح قاعدة أو مسحها.
- اختبارات الواجهة تعرض الدخول بالعربية والإنجليزية والموقع، وتتحقق من غياب بيانات التجربة والادعاءات الكاذبة، وتعطيل الإجراءات غير المنفذة، وبقاء إرسال نموذج الدخول عبر خطاف المصادقة القائم.
- اختبارات API تعمل بقاعدة مؤقتة منفصلة. تتحقق من رفض الكلمة المنشورة دون تعديل مستخدم أو إنشاء جلسة أو حساب، ومن استمرار الدخول بكلمة أخرى، ومن رفض تعيين الكلمة المنشورة إداريًا.
- الفحص الحاسم لهذه الدفعة يسجل منفصلًا مع النسخة وبصمة المصادر؛ لا تستخدم أرقام نسخة التسليم القديمة كنجاح جديد. لا تعد حجب الكلمة المنشورة مراجعة أمان شاملة.

## المتبقي وأول خطوة للاستئناف

ترتيب الدفعات الوارد في توجيه المستخدم محفوظ: أساس الشركات والفروع والصلاحيات والموافقات، ثم محرر القوالب الخمسة والتصميم المتقدم واللقطات التاريخية، ثم الدخول والإعداد ومساحات الأدوار، فالأجهزة والمخزون والتجزئة والمطاعم والمحاسبة والمشتريات وHR وCRM والتكاملات وAI والاشتراكات والإصدار.

لا تصف أيًا منها مكتملًا بمجرد وجود صفحة أو مسار قديم. لا تعِد بناء هوية المستندات أو البائع والعمولات أو المرتجعات المنجزة. لم تُغيّر معرفات السجل الـ73 أو ترتيبها.

المعلومة المطلوبة قبل إعلان قبول الدفعات التالية: الملف التفصيلي المشار إليه في التكليف، ولا سيما معايير القوالب والتحرير التاريخي، وحدود صلاحيات الأدوار والموافقات، وبوابات Windows والأجهزة والعمل دون اتصال. عند وصوله، طابقه مع السجل الحالي وابدأ أساس الشركات والفروع والصلاحيات والموافقات، دون إعادة فتح المنجز أو إنشاء سلسلة اقتراحات مهام.

إن توقفت الجلسة، فهذه حالة محفوظة لا خدمة تعمل في الخلفية بعد توقفها. راجع نتيجة الفحص الأحدث وحالة Git قبل الاستئناف. المخرجات المولدة تحت `generated-artifacts/` مستثناة من Git؛ حفظ المصادر ورفعها ليس نسخة احتياطية من قاعدة البيانات.
