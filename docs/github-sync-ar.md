من أداة Git داخل Replit: تحقق من الفرع، ثم راجع الملفات، وسجّل التغييرات باستخدام Commit عند وجود تغييرات غير مسجلة، ثم استخدم Push.

مسار المزامنة المؤكد في الحالة الحالية هو `sync/hasiba-erp-20261023`. لا تدفع محتوياته فوق `main` أو تنقل ملفاته بناءً على افتراض عن المزامنة السابقة. إذا ظهر دليل على مسار أقدم، يُراجع قبل تغيير الربط أو الفرع المستهدف.

مثال من Shell، مع اختيار الملفات المراد تسجيلها صراحة بدل إضافة الأسرار والمخرجات:

```sh
git branch --show-current
git status
git add <مسارات-الملفات-المقصودة>
git diff --cached --stat
git commit -m "Describe the intended changes"
git fetch github
git merge --ff-only github/sync/hasiba-erp-20261023
git push github HEAD:sync/hasiba-erp-20261023
```

إذا لم توجد تغييرات غير مسجلة فلا حاجة إلى Commit جديد. إذا رفض الدمج السريع بسبب تغييرات لدى الطرفين، توقف لمراجعة الدمج ولا تستخدم الرفع القسري.

نقاط الحفظ الآلية في Replit قد تكون commits محلية، لكنها ليست دليلًا على وصول التغييرات إلى GitHub. لا توجد في هذه المهمة مزامنة مستمرة تلقائية: يلزم Push يدوي أو طلب المزامنة من الوكيل. بعد اعتماد دمج آمن على `main` تُعدّل تعليمات الفرع وفق النتيجة المعتمدة.
