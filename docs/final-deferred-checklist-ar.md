# قائمة الفحص النهائي المؤجل — دون إعادة فتح المنجز المقبول

مرجع قبول شريحة الموردين وأوامر الشراء: المصدرdc24025،وتوثيق7c375b6.
قبولها ضمن أدلتها ثابت؛ البنود التالية حدود دليل مؤجلة، لا إعادة بناء ولا
متطلبات جديدة ولا إعلان وجود عيب غير مثبت:

- تنزيل ملف أمر الشراء عبر الواجهة: رُصد الضغط واختباراتHTTPللملف،
  ولم يُرصد حفظ ملف نظام التشغيل. الإغلاق: دليل تنزيل متصفح وملف فعلي
  صالح صادر من المسار الأصلي، بنطاق مستخدم مصرح.
- تعديل مورد عبر الواجهة الأصلية: لم تشمل رحلة المتصفح المقبولة تعديلًا.
  الإغلاق: تعديل مصطنع مصرح وحفظ وإعادة فتح، ورفض مستخدم غير مصرح،
  دون قراءة أرصدة المورد أو إعادة بناء خدمات التعديل.

لا يبدأ تنفيذ هذين البندين ضمن شريحة استلام المشتريات الحالية.
